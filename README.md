Backend Setup Instructions

   1. When change the directory to the Backend folder 
   2. Ensure that you have Node Js install on your local machine the version should be v18 or higher
        2.1 You can check by running this commands (node -v) and (npm -v)
   3. Run the command (npm install) to install the dependices needed 
   4. Run the command (npm run dev) to start the server
